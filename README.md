# wakeUpDev

![Go Version](https://img.shields.io/badge/Go-1.25-blue.svg)
![Test Coverage](https://img.shields.io/badge/coverage-39.1%25-yellow.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

⏰ Telegram-бот, который отправляет **напоминания по расписанию** в один или несколько чатов.
Учитывает производственный календарь РФ через [isdayoff.ru](https://isdayoff.ru): пропускает выходные,
различает сокращённые дни и умеет отправлять сообщения в последний рабочий день месяца.

## 💡 Возможности

- ⏰ Одно или несколько сообщений по расписанию
- 💬 Несколько чатов с разными сообщениями от одного бота
- 🗂 Настройку через `reminders.json` (с подписями чатов в поле `name`)
- 📝 HTML-форматирование в сообщениях
- 📅 Пропуск выходных и праздников автоматически
- 🎄 Отправку на час раньше в сокращённые (предпраздничные) дни — флаг `pre_holiday_early`
- 📆 Сообщения только в последний рабочий день месяца — флаг `last_working_day`
- ⚙️ Запуск в фоне или в активном режиме
- 🧾 Логи в `./logs/wakeUpDev.log`
- 🐳 Docker
- 🔒 Прокси для Telegram API (HTTP/HTTPS, SOCKS5)

## 📦 Конфиг `reminders.json`

### Формат (несколько чатов)

```json
{
  "chats": [
    {
      "name": "Команда разработки — ворклоги (ПР)",
      "chat_id": -1001234567890,
      "reminders": [
        {
          "time": "18:00",
          "message": "📋 Проверьте ворклоги за сегодня",
          "pre_holiday_early": true
        },
        {
          "time": "17:00",
          "message": "📅 Последний рабочий день месяца — проверьте ворклоги за месяц",
          "last_working_day": true,
          "pre_holiday_early": true
        }
      ]
    },
    {
      "name": "Статус задач — техлид",
      "chat_id": -1009876543210,
      "reminders": [
        {
          "time": "10:00",
          "message": "📊 Статус по задачам на сегодня"
        }
      ]
    }
  ]
}
```

### Поля

| Поле | Уровень | Описание |
|------|---------|----------|
| `name` | чат | *(опционально)* подпись чата в конфиге и логах |
| `chat_id` | чат | ID группы или супергруппы Telegram (`-100...`) |
| `time` | напоминание | Время отправки в формате `HH:MM` |
| `message` | напоминание | Текст сообщения (поддерживается HTML) |
| `pre_holiday_early` | напоминание | *(опционально)* на 1 час раньше в сокращённый день |
| `last_working_day` | напоминание | *(опционально)* только в последний рабочий день месяца |

> **Комментарии в JSON:** стандартный JSON не поддерживает `//` и `/* */`.
> Для подписи чата используйте поле `name`.

### Legacy-формат (один чат)

Старый формат — массив напоминаний без `chat_id` — по-прежнему работает.
В этом случае `GROUP_CHAT_ID` в `.env` **обязателен**:

```json
[
  {
    "time": "10:00",
    "message": "☕ Доброе утро!"
  }
]
```

## 📅 Как работает календарь

Типы дней определяются через isdayoff с `pre=1`:

| Тип | Код | Поведение бота |
|-----|-----|----------------|
| Рабочий | `0` | Сообщение отправляется |
| Выходной / праздник | `1` | Сообщение **пропускается** |
| Сокращённый (предпраздничный) | `2` | Рабочий день; при `pre_holiday_early` — на час раньше |

**Последний рабочий день месяца** — последний день в месяце с типом `0`, `2` или `4`.
Сокращённый день тоже считается рабочим, поэтому если последний рабочий день сокращённый —
напоминание с `last_working_day` всё равно отправится (время сдвинется, если задан `pre_holiday_early`).

### Типичные сценарии

| Задача | Флаги | Результат |
|--------|-------|-----------|
| Каждый рабочий день в одно время | *(без флагов)* | Пн–Пт и сокращённые дни, в одно время |
| Каждый рабочий день, раньше в сокращённые | `pre_holiday_early` | Обычно в 18:00, в сокращённый — в 17:00 |
| Раз в месяц, в последний рабочий день | `last_working_day` | Только в этот день |
| Раз в месяц + сдвиг в сокращённый | оба флага | Последний раб. день; если сокращённый — на час раньше |

## ⚙️ Быстрый старт

1. Склонируйте репозиторий и создайте `.env`:

   ```bash
   make .env
   ```

2. Заполните `.env`:

   | Переменная | Обязательна | Описание |
   |------------|-------------|----------|
   | `BOT_TOKEN` | Да | Токен Telegram-бота |
   | `REMINDERS_FILE` | Да | Путь к `reminders.json` |
   | `TIMEZONE` | Да | Часовой пояс IANA, напр. `Europe/Moscow` |
   | `GROUP_CHAT_ID` | Нет* | ID чата для legacy-формата конфига |
   | `TELEGRAM_PROXY_HOST` | Нет | Прокси: `host:port`, `http://...`, `socks5://...` |
   | `TELEGRAM_PROXY_USERPWD` | Нет | Логин/пароль прокси: `user:password` |

   \* Обязателен, если `reminders.json` — массив без `chat_id`.

   ```env
   BOT_TOKEN=your_telegram_bot_token
   REMINDERS_FILE=reminders.json
   TIMEZONE="Europe/Moscow"
   ```

   **Прокси** включается автоматически, когда `TELEGRAM_PROXY_HOST` не пустой:

   ```env
   TELEGRAM_PROXY_HOST=socks5://127.0.0.1:1080
   TELEGRAM_PROXY_USERPWD=myuser:mypassword
   ```

3. Настройте `reminders.json` — укажите реальные `chat_id` для ваших чатов.

4. Запустите бота:

   ```bash
   make docker-up   # Docker
   make start       # фон, лог в logs/
   make run         # в терминале, лог в stdout
   ```

5. Добавьте бота во **все** целевые чаты и дайте право отправлять сообщения.

## 🛠 Команды Makefile

| Команда | Описание |
|---------|----------|
| `make .env` | Создать `.env` из `.env.example` |
| `make test` | Все тесты, включая Telegram API |
| `make test-short` | Unit-тесты без сети (как при `make build`) |
| `make build` | `test-short` + сборка `./wakeUpDev` |
| `make run` | Сборка и запуск (stdout) |
| `make start` | Сборка, фон, лог в `logs/` |
| `make stop` | Остановка по PID из `run/wakeUpDev.pid` |
| `make logs` | `tail -f logs/wakeUpDev.log` |
| `make clean` | Удалить бинарник, PID и лог |
| `make docker-build` | Собрать Docker-образ |
| `make docker-up` | Собрать и запустить контейнер |
| `make docker-down` | Остановить контейнер |

> **Docker:** при сборке образа — `go test -short`. Секреты в образ не попадают (`.dockerignore`).
> `reminders.json` и `.env` монтируются с хоста.

## 🧪 Тестирование

```bash
make test-short          # быстро, без Telegram API
make test                # полный прогон с .env
go test -short -coverprofile=coverage.out .
go tool cover -html=coverage.out
```

Покрыто тестами: `loadConfig`, `parseHourMinute`, `truncate`, `matchPreHolidaySlot`,
`isNonWorkingDay`, `chatLabel`, настройка прокси.
